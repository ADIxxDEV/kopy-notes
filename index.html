AN INDEPENDENT ALTERNATIVE

Looking beyond
Note3 or Note5?

Kopy Notes is a free, open-source alternative for teachers who want an editable whiteboard, classroom tools and control over their setup.

Use the web version, explore Windows and Android builds, or contribute a feature yourself. This is a growing development project, not a promise of complete feature parity.

Not affiliated with or endorsed by the makers of Note3 or Note5. ENB compatibility is experimental; some content imports as page images.

BEFORE YOUR FIRST LESSON

A few useful answers.

Is Kopy Notes really free?

Yes. The current app is free to use and the core source code is available under MIT. Third-party artwork has separate terms. Future premium themes are a roadmap idea, not a current requirement or subscription.

Will it work without the internet?

Lessons are stored locally. Once the web app and required resources are cached, you can use supported offline features. Keep exported backups: clearing browser storage can remove local lessons.

Can I replace Note3 or Note5 with it?

Try your everyday lessons first. Kopy Notes offers an independent teaching workflow and a familiar org-note3 theme. It is still in development; document fidelity and device support vary.

Where can I download the Windows or Android app?

Available development downloads are listed on GitHub Releases. Builds may be unsigned. You can also run the web version or build the open-source app yourself.
