Digital Board for Teaching: From Blank Page to Reusable Lesson

A digital board for teaching can run on a laptop, tablet or interactive display. Aim for a clear explanation students can follow, with a lesson you can edit and reuse instead of rebuilding it.

By Kopy Notes contributors · Updated 11 October 2026

What is a digital board for teaching?

A digital board combines a writing surface with software for ink, text, diagrams and teaching material. It can run in a browser, on a tablet or on a classroom smartboard. Smartboard often describes the interactive display hardware; digital teaching board can describe the wider software workflow.

This distinction helps schools start with their existing equipment. Prepare an editable lesson on a laptop and project it in class, then assess whether touch input or a larger display would improve that lesson.

Build a simple four-page lesson

  1. Objective: one sentence explaining what students should be able to do. Leave room for an example.
  2. Prediction: a diagram, question or statement students can respond to before you reveal the answer.
  3. Explanation: a worked example with annotations added step by step. Use a highlighter or temporary laser to direct attention without permanently covering the page.
  4. Practice: a short task and an exit ticket. Use a timer where helpful, then save the discussion for revision.

Organize Kopy Notes lessons by subject and use library search to find an existing board. Add a page beside the current explanation and choose a consistent background. Keep prompts as editable text so a new topic does not require redrawing the whole page.

Examples by subject

Mathematics: compare representations

Write an equation, sketch a predicted graph and use the Graph tool to compare. Ask students to connect the equation with intercepts or turning points. In geometry, use the ruler, compass or protractor while explaining each construction step.

Science: predict, observe and explain

Begin with a prediction. Use a diagram, periodic table or available classroom science tool to support the demonstration. Record observations and return to the original prediction to revise the explanation. Software demonstrations use simplified models; they do not replace a supervised practical laboratory.

Languages: preserve the original passage

Import a reading passage as a PDF, highlight evidence and add a short explanation. Create a separate practice page. Export the annotated pages for revision while keeping the editable lesson for another class.

Social science: layer an explanation

Import a map or source image, mark a route with shapes and annotate it in a contrasting color. Keep labels readable from the back row. Reveal detail as the discussion develops instead of showing a wall of text at once.

Share the result and keep it editable

Use PDF for a readable handout and .kopy for an editable teaching file. Kopy's uncompressed portable document format stores supported board objects and attachments. Importing a copy creates a new lesson with new identifiers, making it useful as a template for another class.

Autosave helps while teaching but is not an independent backup. Browser data belongs to a particular profile and website origin. Clearing that storage can remove the library. Export important lessons to a folder outside the browser and keep another copy on a different drive.

A folder already synced by a school's storage provider can hold exported copies where supported. The provider app handles uploading; Kopy Notes does not currently promise direct cloud accounts, live cross-device sync or collaborative classrooms.

Set up Kopy Notes on web, Windows or Android

  1. Web: open the free board, choose your teaching defaults and create a lesson. No account is required for the local workflow. Use the same browser profile next time.
  2. Windows: choose the Windows installer from GitHub Releases. Read the release notes, check the checksum and try a short lesson before teaching with a development build.
  3. Android: choose the APK from the same release page and check your device's installation policy. Development APKs are test-signed, not Play Store certified. Test touch, import and saving on your smartboard.
  4. Offline: open the app, import material and exercise your tools while connected. Then test with the network disconnected. A first browser visit needs uncached app resources.

Current native source includes device-folder backups and display annotation; check release notes for availability in your download. Keep independent exported copies outside browser storage.

Copy a ready-to-edit teaching template

Download Observe, predict, explain (.kopy). The first page asks for a prediction and reason; the second asks for observations and a revised explanation. Change the topic, add a diagram and save your adaptation with a new title.

Try the fractions warm-up or graph-investigation template for another starting point. All three contain original prompts and editable text and shapes.

Digital board questions

Can I start without a smartboard?

Yes. Try the web app on a laptop or tablet first. A projector displays the lesson; an interactive display adds touch but is not required to prepare notes.

Is imported PDF text editable?

PDF content is rendered as document pages, not converted into fully editable text. You can annotate and arrange it; .kopy preserves your added annotations and supported board objects.

Can I teach with limited internet?

Prepare the app and lesson while connected, then verify the supported offline workflow on your device. Keep local material and exported backups ready.
