# Note3 reference review

Sources: supplied screenshots, the [official product page](https://prestigio-solutions.com/product/note3-interactive-whiteboard-software), and the [93-page user guide, version 1.0.2](https://prod-cdn.prod.asbis.io/s3/cms/document/80/bc/80bcca968eba8ea466cacaa276a34a27/note3_user_guide.pdf). This is a feature review and independently implemented interface, without vendor source or artwork.

The guide covers file/import/export, backgrounds, subject resources, selection, handwriting, erasing, shapes, roaming, recognition, page management and presentation modes. Its subject sections cover mathematics, English, physics and chemistry. The supplied screenshots remain the layout reference.

See [FEATURE_MATRIX.md](FEATURE_MATRIX.md) for implementation status. Kopy now has transparent constrained-drawing instruments, pressure rendering, group selection/resizing, PDF lesson pages, editable portable files, recovery copies and several folder destinations. Native hardware checks, OCR/math recognition, interactive 3D, broader subject libraries, page grouping, desktop annotation and long-session recording remain work to complete. Claims of parity should follow verified behavior on actual classroom hardware.

The 0.2.0 interaction update follows guide pages 63–68 for visible page management and sorting, 79–81 for instrument grips and compass sweep, and 59–62 for shape styling. The sidebar adds keyboard ordering. Vendor source/artwork are not included.
