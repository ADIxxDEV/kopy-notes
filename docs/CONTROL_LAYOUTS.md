# Arrange your classroom controls

Controls dock against the screen edges by default. On tablets, drawing tools use the left edge, slide thumbnails open on the right, and file/page controls sit at the bottom corners. Smaller screens scroll the vertical tool dock.

Open **Teaching controls → Customize all controls**, or tap the layout icon on the right edge.

1. Choose a button or panel from **Control**.
2. Drag it along a screen edge. Turn on **Floating control** to place it anywhere.
3. Adjust **Size** or **Hide this control**. Hidden controls remain selectable in the editor.
4. Enter a name and select **Save preset**. Select **Apply layout** to use the arrangement.

Selecting a saved preset previews it; Apply makes it active. Cancel restores the previously active arrangement. Update preset replaces the selected preset. Reset this control restores one default; Default layout restores the complete arrangement.

Calculators, timers, comments and other tool panels open docked. Their header has a **Float / Dock** button. Docked panels can slide along their edge. Tools opened after applying a preset use that preset's saved position.

Layouts use proportional positions so they stay reachable when a tablet rotates. Large controls are fitted to the available screen. Keep separate named presets for phone, tablet and smartboard arrangements when useful.

Export downloads `kopy-control-layouts.json`, containing the current layout and up to 20 presets. Import restores it on another device. Layouts are stored in this browser profile, separately from lesson content; export a copy before clearing site data.

The layout editor itself can be moved by its header or minimized to reach controls behind it. The layout launcher stays on the screen edge so hidden controls can always be restored.
